# منظومة زوار المستشفى (HVMS)

تطبيق Flutter بواجهة عربية من اليمين إلى اليسار لإنشاء تقارير حركة الزوار وإرسالها يدويًا عبر واتساب.

## النطاق المعتمد
- إدخال رقم الغرفة وعدد الزوار.
- تسجيل التاريخ تلقائيًا، مع تسجيل وقت الدخول والخروج من أزرار مخصصة.
- إضافة ملاحظات اختيارية.
- إنشاء تقرير PDF باللغة العربية.
- حفظ نسخة من ملف PDF محليًا على الهاتف.
- فتح قائمة المشاركة في الهاتف ليختار المستخدم واتساب ويرسل التقرير إلى المشرف.

## الخصوصية وطريقة العمل
- لا يستخدم التطبيق Firebase أو Firestore أو قاعدة بيانات عن بُعد.
- لا تُرفع سجلات الزوار إلى خادم من التطبيق.
- بيانات النموذج تبقى مؤقتة في الشاشة، ويُحفظ التقرير النهائي كملف PDF في مساحة ملفات التطبيق على الهاتف.
- يختار المستخدم واتساب يدويًا من قائمة المشاركة. لا يرسل التطبيق الرسالة تلقائيًا ولا يختار المستلم بدلًا عن المستخدم.
- إذا حُذفت بيانات التطبيق أو أُزيل التطبيق، فقد تُحذف ملفات PDF المحفوظة داخل مساحة التطبيق؛ لذلك يُنصح بإرسال التقارير أو نسخها إلى مكان آمن عند الحاجة.

## ملاحظات تقنية
- Flutter / Dart.
- تستخدم الحزم `pdf` و`printing` لإنشاء PDF بخط عربي، و`path_provider` لحفظ الملف محليًا، و`share_plus` لمشاركته.
- شاشة تسجيل الدخول الحالية واجهة فقط؛ لا يوجد تحقق فعلي من الحسابات أو صلاحيات مستخدمين لأن النظام لا يستخدم خادم مصادقة.
- لا تُشغّل عمليات بناء APK تلقائيًا. لا تُنشأ نسخة بناء إلا عند طلب المستخدم صراحةً.
