# منظومة زوار المستشفى (HVMS)

تطبيق Flutter بواجهة عربية من اليمين إلى اليسار لإدارة دخول النظام وطلبات حسابات العاملين، مع وظائف تسجيل الزوار والتقارير.

## وظائف التطبيق الحالية
- تسجيل الدخول عبر Firebase Authentication (البريد الإلكتروني وكلمة المرور).
- إرسال طلب حساب جديد لدور ضابط أمن أو مشرف.
- إبقاء الحساب غير قادر على دخول النظام حتى يعتمد المسؤول الطلب.
- شاشة مسؤول لمراجعة طلبات الحسابات والموافقة عليها أو رفضها باستخدام Firestore مباشرة، دون Cloud Functions.
- تسجيل الطابق والقسم ورقم الغرفة وعدد الزوار وأوقات الدخول والخروج والملاحظات.
- حفظ سجل الزيارة في مجموعة `visitor_logs` في Firestore بعد اكتمال وقت الدخول والخروج.
- إنشاء تقرير PDF يتضمن الطابق والقسم، وحفظه على الهاتف ومشاركته.

## إعداد Firebase
1. أنشئ مشروع Firebase واربط تطبيق Android باستخدام package name الموجود في إعداد Firebase.
2. ضع ملف `google-services.json` في `android/app/google-services.json`.
3. فعّل Email/Password من Authentication.
4. انسخ محتوى `firestore.rules` إلى Firebase Console > Firestore Database > Rules ثم اضغط Publish.
5. أنشئ حساب المسؤول في Authentication، ثم أنشئ يدويًا مستند `users/{UID}` له من Firebase Console بالحقول:
   - `role`: `admin`
   - `status`: `active`
   - `displayName`: اسم المسؤول
   - `email`: بريده الإلكتروني
6. حدّث اعتماديات Flutter عبر `flutter pub get` عند البناء.

## آلية الموافقة بدون Cloud Functions
- يمكن للموظف إنشاء حسابه وإرسال طلبه بنفسه.
- يقرأ المسؤول الطلبات المعلقة من Firestore داخل التطبيق.
- الموافقة تنشئ ملف الموظف وتحدّث الطلب ضمن عملية ذرّية واحدة.
- قواعد Firestore تتحقق من أن صاحب قرار الموافقة مسؤول فعّال، وتسمح فقط بالدورين `security_officer` و`supervisor`.
- عند الرفض، يبقى حساب المصادقة موجودًا لكن لا يستطيع دخول النظام؛ إذا سجّل الدخول لاحقًا، يمكنه إعادة تقديم طلبه.
- لا يستطيع المستخدم إنشاء أو تعديل مستند ملفه ليمنح نفسه صلاحية فعّالة.

## الطوابق والأقسام المعتمدة
- الطابق الخامس: العناية الحثيثة للحروق (ICU Burns).
- الطابق الرابع — الجراحات التخصصية: جراحة العظام رجال، جراحة العظام نساء، قسم الأطفال.
- الطابق الثالث — الباطنية: رجال، نساء.
- الطابق الثاني — الجراحة: رجال، نساء.
- الطابق الأول — التوليد والولادة: التوليد والولادة، الأطفال حديثو الولادة.
- مستوى مستقل: العناية القلبية الحثيثة (CCU) وخدمات القلب والقسطرة.

## سجلات الزوار والصلاحيات
- تحفظ الزيارات في مجموعة `visitor_logs` بعد تسجيل وقت الدخول والخروج.
- يحتوي السجل على الطابق والقسم والغرفة وعدد الزوار والأوقات والملاحظات وهوية الموظف المنشئ ووقت إنشاء السجل.
- تسمح قواعد Firestore للموظفين النشطين بإنشاء سجلاتهم، وتسمح للموظف بقراءة سجلاته، وللمشرف والمسؤول بقراءة جميع السجلات.
- سجلات الزيارات غير قابلة للتعديل أو الحذف من التطبيق للحفاظ على أثر التدقيق.
- يجب نشر ملف `firestore.rules` المحدّث من Firebase Console حتى يعمل الحفظ السحابي.

## ملاحظات المرحلة الحالية
لوحات الإحصاءات والبحث والتقارير اليومية العامة ما زالت بحاجة إلى ربط فعلي في مرحلة لاحقة؛ لا تُعامل الأرقام أو الأزرار التوضيحية القديمة على أنها تقارير مباشرة من قاعدة البيانات.
