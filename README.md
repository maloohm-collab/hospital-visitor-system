# Hospital Visitor Management System (HVMS)

منظومة إدارة زوار المستشفى — مشروع مستقل مبني باستخدام Flutter وFirebase، بواجهة عربية تدعم اتجاه RTL.

## الهدف
تنظيم تسجيل زوار المستشفى ومتابعة أوقات الدخول والخروج، مع البحث والتقارير والصلاحيات المناسبة.

## النطاق الأولي
- تسجيل الدخول وإنشاء الحساب.
- انتظار موافقة المسؤول على الحسابات الجديدة.
- لوحة مسؤول لإدارة الموافقات.
- تسجيل بيانات الزائر وربط الزيارة بالقسم أو المريض وفق صلاحيات المستشفى.
- تسجيل وقت الدخول والخروج والبحث في السجلات.
- تقارير وإحصاءات أساسية.

## التقنية
- Flutter (Android وiOS)
- Firebase Authentication للحسابات
- Cloud Firestore للبيانات
- قواعد أمان Firestore للصلاحيات

## مبدأ التنفيذ
البساطة أولاً: بناء تدريجي، دون إضافات غير ضرورية، مع حماية بيانات المرضى والزوار.

## إعداد التطوير
1. ثبّت Flutter وDart.
2. أنشئ إعداد Firebase الخاص بالمشروع.
3. لا ترفع مفاتيح أو أسرار أو ملفات إعداد خاصة غير مناسبة إلى Git.

## حالة المشروع
مرحلة تأسيس الملفات الأساسية. ستُضاف الشاشات والربط مع Firebase تدريجياً مع اختبار كل مرحلة.
