# Hospital Visitor Management System (HVMS)

منظومة إدارة زوار المستشفى — مشروع Flutter مستقل بواجهة عربية RTL وتصميم هادئ وواضح.

## الشاشات الموجودة حالياً
- شاشة ترحيب وبداية الاستخدام.
- واجهة تسجيل الدخول وإنشاء الحساب (واجهة أولية).
- لوحة رئيسية بملخصات وخدمات سريعة.
- نموذج تسجيل زائر والتحقق من الحقول.
- واجهة أولية لمراجعة طلبات الحسابات من المسؤول.
- اختبار واجهة أساسي وسير عمل GitHub Actions للتحليل والاختبارات.

## التقنية
- Flutter / Dart
- Firebase Authentication وCloud Firestore مخططان للربط في المرحلة التالية.

## حالة التنفيذ
الواجهات الأساسية موجودة، لكن تسجيل الدخول وإنشاء الحساب وحفظ الزوار والموافقات والإحصاءات **ليست مرتبطة بقاعدة بيانات بعد**. الأرقام الحالية تعرض شرطات عمداً حتى لا تظهر بيانات وهمية على أنها حقيقية.

## الخطوات التالية
1. إعداد مشروع Firebase وإضافة إعدادات المنصات من حساب مالك المشروع.
2. تنفيذ المصادقة والتحقق من حالة الحساب.
3. تطبيق صلاحيات المسؤول وقواعد Firestore الآمنة قبل تخزين أي بيانات.
4. ربط تسجيل الزوار وسجل الدخول والخروج بالبيانات الفعلية.
5. تشغيل التحليل والاختبارات ومعالجة أي أخطاء.

## الأمان والخصوصية
- لا ترفع مفاتيح خاصة أو ملفات أسرار إلى Git.
- بيانات الزوار والمرضى حساسة؛ يجب تقليل البيانات المجمعة وتقييد الوصول إليها بقواعد خادمية مناسبة.
- لا تمنح أي حساب صلاحية مسؤول اعتماداً على قيمة يحددها المستخدم في الواجهة.
